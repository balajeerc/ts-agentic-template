# Committing Code

- Do not mention any AI assistant or model vendor branding in commit messages.
- Do not add "co-authored by" trailers for an assistant.
- Commit messages should balance detail and brevity.
- Bulleted, multi-line commit messages are encouraged.
- Ideally keep the message under about 5 lines.
- Commit or push only when asked. If on the default branch, branch first.
